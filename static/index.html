每个旋钮是什么 · 怎么调 · 调了会怎样
🧠思考区思考开启时，下方采样参数不生效（DeepSeek 行为）
思考模式开

开关"先想后答"。开启时回复上方出现 💭 思考链（已保存，点开可看推理过程）。

问"为什么/分析"类开着；查事实、闲聊可关掉，速度翻倍
思考强度high

推理深度。low 实际等同 high；max 更深，但多耗 50-200% 推理 token、慢 30-100%。

写诗、日常用 high；数学证明、系统架构设计用 max
🎛️采样区控制"回答的风格"，不影响记忆
temperature 温度1.0

随机性：0 = 最确定保守（事实/代码），越高越有创意发散（写作）。

查资料 0.3；写诗 1.3；头脑风暴 1.5
top_p1.0

核采样，效果类似温度。一般保持 1.0，和温度二选一调即可。

想收着点写 → 0.9；想放飞 → 保持 1.0 不动
max_tokens4096

单次输出上限（含思考链）。太小会被截断——会弹 ⚠ 提示，不是 bug。

短回答 1024；长文/报告 8192；思考模式建议 4096 起步
presence_penalty0.0

话题新鲜度惩罚（-2~2）：越大越倾向聊新话题、不重复说过的话。

觉得它总绕回老话题 → 拉到 0.6
frequency_penalty0.0

用词重复惩罚（-2~2）：越大用词越多样，避免车轱辘话。

写作时嫌它词穷 → 0.5
流式输出开

逐字显示（推荐，能看到思考进度）；关闭则一次性返回整段。

默认保持开启即可
🗂️记忆区这些是"上下文容量"的管理旋钮，也是命中率的核心
上下文档位标准

一键预设：轻量 8k / 标准 12k / 深度 32k / 极限 100k（历史原文预算），阈值自动配套。

日常聊天标准档；长文档讨论深度档；拖滑块会变"自定义"
历史 token 预算12,000

每轮把最近多少 token 的对话原文放进上下文（水池容量）。超出部分先裁剪、后被摘要吸收，不会丢。

12k ≈ 一两万字对话；想让它逐字记住更久 → 调大
摘要重写阈值16,000

未摘录对话累积超过多少 → 触发一次压缩：旧内容交给 LLM 压成要点进长期记忆（会清一次缓存，⚠ 正常）。

16k ≈ 每聊 1.5 万字自动整理一次；想整理更频繁 → 调低
记忆检索开

是否把已抽取的事实（📌 长期记忆）按重要度注入对话。关闭后 Gili 只靠本会话内容回答。

想让它记得你的偏好 → 保持开；要极简上下文 → 关
💡 缓存小知识：没有"缓存开关"——DeepSeek 的缓存自动生效。你能做的只有保持提示词前缀稳定： 稳定区（人设+技能）和低频区（摘要+记忆）不变，缓存就一直命中；任何变动都会打 ⚠ 并付一次全价。 命中率、失效事件、成本都在「数据」面板实时可见。
