# Gili Agent

一个"专门属于我"的个人 AI 伙伴 —— 本地桌面应用，只对接 DeepSeek（深度优化**前缀命中率**与**记忆**），当前核心闭环完整可用，学习知识库阶段 A 已上线。

> **当前状态：v0.29 稳定** —— 对话 / 记忆 / 联网搜索 / 学习模式 / 人格画像均已可用；流式输出可一键「⏸ 暂停」（部分回答自动保留）、发送队列卡片化（一条需求一行）；画像系统（docs/13）：大五+行为八维、默认关闭、每 20 轮自动分析、八角雷达图；联网用 DeepSeek 官方原生搜索；命中率修复后单会话 82-88%（docs/12）；测试套件 30 项 + HTTP 冒烟。

## 快速开始

```bash
pip install -r requirements.txt
```

**方式一：桌面版（推荐）** —— 原生窗口，有任务栏图标，不占浏览器标签页

```bash
python desktop.py        # 或直接双击「启动桌面版.bat」
```

**方式二：浏览器版** —— 方便调试

```bash
uvicorn app.main:app --reload
```

打开 http://127.0.0.1:8000

**开发者自检**（每批改动后）：
```bash
python -m pytest              # 单元测试 19 项（零 API 成本，隔离数据）
python scripts/smoke.py 8100  # HTTP 冒烟 22 项（需服务器已启动）
node scripts/check-ui.mjs     # 前端回归（孤儿 id + 重复函数哨兵）
```

首次使用：点侧边栏 **⚙ 设置** 填入 DeepSeek API Key → **测试连接** → 保存。未填 key 时聊天自动使用模拟回复。

**前缀稳定性是第一公民**：prompt 按「稳定区 → 低频区 → 波动区」固定顺序组装，记忆摘要阈值触发才重写，命中率全程可观测。
