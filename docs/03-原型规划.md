## 4. 假数据设计

- **mock 会话**：3 条（"关于 Gili Agent 的想法"/"DeepSeek 缓存优化笔记"/"周末读什么书"）
- **mock 记忆**：核心 2 条 + 长期 1 条（内容贴近真实使用场景）
- **mock 指标**：8 条请求日志，模拟一次典型高命中会话：首请求 0% 命中 → 逐步爬升至 93.9%（体现"首轮 miss、后续 hit"的真实形态），附带成本/延迟
- **mock 回复**：MockProvider 逐字流式吐出，明确标注「原型模式 · 模拟回复」
