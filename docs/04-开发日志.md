- 从零做，不 fork 大平台（Open WebUI/LobeChat 等）；参考 [pi-deepseek-cache](https://github.com/ruanbw/pi-deepseek-cache) 的三件套模式 + [Mem0](https://github.com/mem0ai/mem0) 的记忆思路
- 最终形态：**本地桌面应用**（pywebview 原生窗口 + FastAPI + SQLite），数据全本地
- 核心优化目标：**DeepSeek 前缀命中率** + **三层记忆**，全程可观测（命中率/成本/失效事件）
- 产品三阶段：对话伙伴（✅）→ 对话收藏（✅）→ 学习知识库（阶段 A 已实施，B/C 待做）

## 2. 核心设计原理（浓缩）

### 2.1 前缀命中率（第一公民）

- DeepSeek 缓存：自动、按前缀、块匹配，命中价 ≈ 未命中 1/10；不可强制，只能靠请求结构
- **三区固定顺序**：`[稳定区 人设+技能静态片段] [低频区 摘要+记忆条目] [波动区 历史+环境注入+当前消息]`
- **前缀指纹**：稳定区+低频区 SHA-256；指纹变化 = 缓存失效（请求日志打 ⚠）
- 失效四来源：技能切换 / 摘要重写 / 记忆编辑 / 历史裁剪（全部记账）
- 裁剪原则：只从开头整条丢（确定性），两次裁剪间前缀稳定
- 动态内容（时间戳）只进波动区，绝不进稳定区

### 2.2 三层记忆（水池比喻）

- 核心记忆 core = Soul（人设），几乎不变
- 工作记忆 = 近期对话（messages 表，summarized=0），预算裁剪
- 长期记忆 = 事实条目 + 每会话滚动摘要（kind=fact / summary）
- **历史预算 = 水池容量**（每轮逐字原文上限）；**摘要阈值 = 预警线**（超过触发压缩）
- 压缩后保留窗口 = **预算 × 0.35**（2k~40k 区间），预算越大保留越多
- 原文永不删除（summarized=1 标记），数据归用户

### 2.3 上下文档位

| 档位 | 历史预算 | 摘要阈值 | 压缩后保留 |
|---|---|---|---|
| 轻量 | 8k | 10k | 2.8k |
| 标准（默认）| 12k | 16k | 4.2k |
| 深度 | 32k | 40k | 11.2k |
| 极限 | 100k | 110k | 35k |

模型「1M」是能力上限（不可调），档位是实际使用水位（可调）。阈值 > 预算的间隙是"滑动裁剪期"（每轮缓存失效的固有成本）。

## 3. 踩坑与修复记录（根因级别）

| # | 症状 | 根因 | 修复 |
|---|---|---|---|
| 1 | 桌面版双击没反应 | bat 中文 + chcp 65001 在部分控制台解析错乱 | 纯 ASCII bat + pythonw 的 .lnk |
| 2 | 指标接口 500 | 假数据缺 hit_rate 字段，汇总直接取 | hit_rate 由 hit/prompt 现算（单一数据源）|
| 3 | 聊天区无法下滑 | grid 只定义列未定义行，行高 auto 撑爆视口 | `grid-template-rows: minmax(0,1fr)` + min-height:0 |
| 4 | 数据面板不动（**关键**）| 实测 DeepSeek 流末块 choices 与 usage **同时存在**，`elif chunk.usage` 永远不执行 → usage 从未捕获 | usage 判断改独立 `if`（实测 hit/miss 落库）|
| 5 | 聊天多出"自我介绍" | 启动欢迎气泡是幽灵消息（不落库、不属于任何会话）| 删除气泡 → 空态占位 + `_booted` 防重入 |
| 6 | 消息顺序可能乱 | created_at 秒级精度，同秒多条无兜底 | `ORDER BY created_at, rowid` |
| 7 | 命中率曲线显示旧数据 | `ORDER BY ts ASC LIMIT 40` 取的是最早 40 条 | DESC 取最近再反转 |
| 8 | 历史裁剪不在日志打 ⚠ | 指纹只覆盖稳定+低频区 | get_context_messages 返回裁剪标志，并入失效判断 |
| 9 | max_tokens 滑块 422 | schemas 限制 8192，config/UI 到 131072 | 统一 131072 |
| 10 | 手动压缩"没有内容" | 只压保留窗口（4k）之外的旧消息，短对话无内容 | 手动按钮 force 模式（只留最近 2 条）|
| 11 | 压缩窗口与预算脱节 | 保留窗口固定 4000 与档位无关（100k 预算白设）| 保留 = 预算 × 0.35 |
| 12 | 后台摘要任务异常被吞 | create_task 无引用 | try/except 包裹打印 |
| 13 | 假数据污染汇总命中率 | demo 与真实混算 | 删除全部假数据，live/demo 分离（现只有真实）|

| 15 | 测试连接 APIConnectionError | `base_url` 被空串覆盖默认值 → OpenAI SDK 找不到目标 | `config.load()` 空值回退默认 + `make_provider` + `test_settings` 四层兜底 |
| 16 | 学习项目创建 500 | SQL `VALUES` 少一个 `?`（9 个占位符 vs 10 个参数） | 补全占位符 |
| 17 | 气泡顶部多余空行 | 模板字符串多行换行 + `white-space: pre-wrap` → 换行被渲染成真实空行 | 模板改为单行 |
| 18 | 搜索技能正文重复 | 探测轮不搜索时既输出了结果又跑了第二次流式 | `needs_stream` 标志位，不搜索时跳过二次流式调用 |
| 19 | 侧边栏启动白板 | `init()` 里 `loadConversations()` 串行最后执行，网络慢时 1-2s 空白 + 无兜底 | 提为最高优先级并行 + 1.5s 兜底重试 + DocumentFragment 批量渲染 |
| 20 | **全部按钮失效 + 列表空白（严重）** | 删除 HTML 元素 `#in-metrics-conv` 后残留 JS 绑定 `$("#in-metrics-conv").addEventListener(...)` → `null.addEventListener` → TypeError → 整个脚本中断，其后所有绑定与 init() 全部失效 | 删除残留绑定 + 引入"JS id ↔ HTML id 孤儿引用核对"脚本作为回归检查 |
