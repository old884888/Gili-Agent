# 学习模式设计（阶段三：结构化学习 + 知识库）

> 版本：v1.0（设计定稿）｜日期：2026-08-06｜状态：**阶段 A 已实施**（B/C 待做）
> 前置阅读：docs/01-设计文档.md（三阶段演进）、docs/05-记忆系统进化设计.md

## 1. 背景与目标

**用户场景**：学习 Python 等新知识时——AI 回答引出旁支概念（学 C 提到 K），路径变成 ABCK，忘记主线；跨学科知识（编程中学心理学）需要归档到对应分类。

**三个核心目标**：

| 目标 | 解法 |
|---|---|
| 结构化学习闭环 | 流水线创建计划 → 文档产物 → 学习中心 → 打勾进度 |
| **ABCK 迷路** | 知识锚点 + 疑问挂起 + 分支归档（§5） |
| **跨学科归档** | 知识库按主题分类，对话中说"记到 XX"即归档 |

## 2. 核心概念

```
学习项目（Learning Project）= 一个学科的一套结构化文档
├─ 学习大纲（md）      路线图：阶段 → 章节 → 目标
├─ 进度跟踪表（表格）   章节 | 状态 | 日期 | 备注 —— 打勾在这
├─ 知识笔记（md）      你的笔记 + AI 整理（版本化）
└─ 疑问本（md）        挂起的旁支概念（K）清单，带出处

知识库（Knowledge Base）= 按主题分类的笔记集合（心理学/编程/写作…）
```

**存储决策（已确认：混合）**：
- SQLite：项目元数据、进度打勾、章节状态、疑问条目（结构化查询）
- md 文件：大纲/笔记/疑问本的内容（`notes/<project>/` 目录，可被 Obsidian 打开）
- 导出与备份天然支持（文件即内容）

## 3. 创建流程（v0.15 对话式引导，状态机）

```
点顶栏「🎓 学习模式」→ 当前对话变成学习专用，AI 在对话里发第 1 问
  → 1/4 想学什么（"Python"，气泡下选项卡或直接打字）
  → 2/4 当前水平（零基础/入门/进阶，选项卡）
  → 3/4 目标水平（入门/进阶/精通，选项卡）
  → 4/4 计划风格（详细 vs 精炼，选项卡）
  → AI 贴出确认摘要（✅ 确认创建 选项卡 / 打字确认）
  → AI 实时生成 4 份文档（⏳ 进度消息 → 🎉 完成消息，都在对话里）
  → 文档入口 = 顶栏「📖 学习文档」
```

- 后端：会话级状态机（learning.py `_onboard[cid]`），引导消息直接落库到对话（messages 新列 `quick_options` 存选项卡 JSON）
- UI：引导消息气泡下方渲染选项卡（点击=回答），打字回答同样走状态机（/api/chat 拦截，不调 LLM）
- 已有项目的会话再点学习模式 → 提示直接看文档；项目创建后会话自动改名「{科目}学习笔记」

## 4. 数据模型（混合）

**SQLite 新表**：

| 表 | 字段 |
|---|---|
| `learning_projects` | id, subject, level_from, level_to, style, status(active/paused), progress_pct, created_at |
| `learning_chapters` | id, project_id, title, order_no, status(pending/learning/done), note, updated_at |
| `learning_questions` | id, project_id, question, concept, source_ref, status(pending/resolved), created_at |
| `learning_notes_meta` | id, project_id, filename, title, version_no, updated_at（内容在 md 文件）|

**md 文件**：`notes/<project_id>/大纲.md`、`进度表.md`、`笔记.md`、`疑问本.md`（可被 Obsidian 打开）

## 5. ABCK 迷路三机制（核心）

### 5.1 知识锚点 📍
- 大纲/进度表顶部渲染"📍 当前位置：第 N 章 / N 个已掌握 / 当前疑问 X 条"
- 打开学习中心任何卡片 → 锚点最显眼 → "我在哪"永远有答案

### 5.2 疑问挂起（已确认：AI 建议 + 用户确认）
- AI 回答中出现旁支概念 K → 建议条：「K 是旁支概念，**挂起**到疑问本，还是现在展开？」
- 挂起 → 入疑问本（concept + 出处 + 一句话解释）→ 主线继续
- 疑问本里的 K 随时可捡回（点卡片 → "继续展开 K"）
- 实现：学习模式下对话的后处理（LLM 检测旁支概念 → 前端建议条）

### 5.3 分支归档（跨学科）
- 用户说「记到心理学」→ LLM 分类 → 写入心理学知识库（`notes/知识库/心理学.md` 追加）
- 不打断当前学习主线；跨学科知识按主题各自积累

## 6. 学习中心 UI（悬浮球）

```
悬浮球（固定右下角，不随滚动消失）→ 学习中心面板
  └─ 项目卡片列表（Python 32% ██████░░ / 心理学 5%…）
       └─ 点卡片 → 大弹窗：
            ├─ 锚点条（当前位置）
            ├─ Tab：大纲 / 进度表 / 笔记 / 疑问本
            ├─ 进度表：章节行 + ☑ 复选框（点击打勾，进度实时算）
            ├─ 笔记：md 编辑器（写/改）+ 右上角 🤖 整理（版本化，可回退）
            └─ MD 渲染 / 源码切换（复用现有 md-toggle）
```

- 悬浮球跨滚动常驻：`position: fixed`，聊天区右下角
- 进度百分比 = done 章节 / 总章节，显示在卡片与锚点

## 7. 与现有系统的边界（缓存与记忆）

- **计划文档不进提示词**（避免拖家带口）：学习内容按需引用——你问"我学到哪了"才检索项目状态注入
- 学习项目状态（进度/当前章节）作为**常驻事实的候选**（⭐3 注入低频区：当前学习项目 + 进度一句话）
- 复用：Markdown 渲染、版本机制（AI 整理 = 新版本可回退）、FTS 检索、`学习模式` 技能占位激活
- 记忆抽取照常工作（学习中的事实照常进长期记忆）

## 8. API 设计

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/learning/mode` | 进入/推进学习模式（按会话；answer 缺省=进入，带 answer=推进/确认） |
| POST | `/api/learning/projects` | 确认创建（备用入口，调 LLM 生成 4 份文档） |
| GET | `/api/learning/projects` | 项目列表（含进度） |
| GET | `/api/learning/projects/{id}` | 项目详情（章节/疑问/锚点） |
| POST | `/api/learning/chapters/{id}/status` | 打勾（pending→done） |
| POST | `/api/learning/questions` | 挂起疑问 / 标记解决 |
| GET/PUT | `/api/learning/notes/{id}` | 读/写笔记 md 内容 |
| POST | `/api/learning/notes/{id}/organize` | AI 整理（版本化） |
| POST | `/api/learning/classify` | "记到 XX" 跨学科归档 |

## 9. 实施计划

### 阶段 A：骨架（✅ 已实施，2026-08-06）
1. DB 四表 + notes/ 目录 + learning.py（onboarding 状态机 + LLM 生成章节 + 4 文档写入）
2. Onboarding：step-bar 步骤条（4 步流水线 → 确认摘要 → ✅ 确认创建） + 快捷科目 chips
3. 学习中心：悬浮球（右下角固定）→ 项目卡片（标题/进度条/状态）+ 详情弹窗（Tab 大纲/进度表/笔记/疑问本 + MD 渲染/源码切换）
4. 实测：Pipeline 创建 Python 项目（10 章 + 4 份 md 文档，1938 bytes 大纲），全链路通

### 阶段 B：进度与笔记（打勾 + 编辑 + AI 整理）
1. 进度表打勾 → 进度百分比 → 锚点条
2. 笔记编辑器 + 保存 + 🤖 整理（版本化回退）
3. 验收：学完章节打勾 → 进度变；写笔记 → AI 整理 → 版本切换

### 阶段 C：ABCK 与归档（迷路三机制）
1. 疑问挂起：学习对话后处理检测旁支 → 建议条 → 挂起/展开
2. 分支归档："记到 XX" → 知识库分类写入
3. 知识锚点在卡片/弹窗常驻
4. 验收：学 C 提到 K → 挂起 K → 主线不回退；问心理学 → 记到心理学

## 10. 验收标准（总）

- [ ] 5 步流水线创建 Python 项目 → 4 份文档生成 → 悬浮球出现
- [ ] 学完 2 章打勾 → 进度 2/N → 锚点更新
- [ ] 对话中 AI 建议挂起旁支 → 确认 → 疑问本出现 K → 主线继续
- [ ] "记到心理学" → 心理学知识库新增条目，编程计划不变
- [ ] 笔记编辑保存 + AI 整理 + 版本回退
- [ ] 重启应用：项目/进度/笔记全在

## 11. 不做（记录在案）

- 番茄钟/专注计时（学习会话时长统计）
- 学习计划自动排期（日历联动）
- 知识卡片闪卡复习（Anki 式）——可作下一阶段
- 多人共享学习项目
